# 27 November 2026 – Apache Cassandra DBA Master Program adopted for VJCLAB learning

## Objective

Add the user-provided six-page `Apache Cassandra DBA Master Program.pdf` to the project's study framework and use its 18 curriculum sections as the structured learning path for the Live Banking Transaction Application lab.

## Source reviewed

The uploaded document is titled `Apache Cassandra DBA Master Program` and contains an 18-section curriculum. It covers:

1. NoSQL fundamentals and Apache Cassandra overview.
2. Installation and environment setup.
3. Cassandra architecture.
4. Cassandra internals (read and write path).
5. Data modeling fundamentals.
6. Advanced data modeling.
7. CQL basics.
8. Advanced CQL and best practices.
9. Indexing and query optimization.
10. Security and access control.
11. Multi-node cluster setup and operations.
12. Daily DBA operations (nodetool).
13. Repair and maintenance.
14. Backup and restore.
15. Point-in-time recovery (PITR).
16. Monitoring and observability.
17. Performance tuning and troubleshooting.
18. Upgrade, migration and modern deployments.

The source describes a practical, production-oriented approach using hands-on labs, real-world scenarios and live demonstrations. The source syllabus transcription preserves its section names and topic list.

## Learning environment adaptation

The learning roadmap uses the existing lab rather than rebuilding it:
- CentOS Stream 9.
- Apache Cassandra 4.1.12.
- VJCLAB three-node cluster (192.168.62.134, .135, .136), dc1.
- `banking_stream` synthetic banking workload.
- Python Cassandra driver and shared connection factory.
- Prometheus, Node Exporter, JMX Exporter and Grafana.

Version-sensitive subjects are explicitly separated. The source lists SAI under Cassandra 5.x and rolling upgrade from 4.x to 5.x; these will be studied as future Cassandra 5.x/upgrade-lab topics, not applied to the current 4.1.12 cluster. K8ssandra and cloud Cassandra are initially architecture studies, not workloads for the resource-constrained VMs.
