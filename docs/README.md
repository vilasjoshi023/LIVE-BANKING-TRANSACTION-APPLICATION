## Documentation rules
- Keep the date and environment for each observation.
- Distinguish actual errors from hypothetical troubleshooting guidance.
- Record root cause only when supported by evidence; otherwise label it as a hypothesis.
- Capture before/after validation and performance impact.
- Redact secrets, customer data and private infrastructure credentials.
